鍔熻兘

汇总统计

顶部展示 5 个关键指标：总交易数、盈利数、亏损数、总盈亏、胜率。

筛选器

  • 搜索: 按标签/出场原因搜索
  • 交易对: 下拉筛选具体交易对
  • 方向: 多头 / 空头
  • 结果: 盈利 / 亏损
  • 日期范围: 开始日期 → 结束日期

排序

点击列表头可排序：交易对、盈亏、收益率、持仓时长。支持升序/降序切换。

CSV 导出

点击 “导出 CSV” 按钮将当前筛选结果导出为 UTF-8 CSV 文件，含 BOM 头以兌容 Excel 中文显示。

分页

每页 20 条记录，支持上一页/下一页导航。

强制平仓

开仓交易在操作列显示 “强制平仓” 按钮，点击后可选择市价/限价下单。

相关 API

端点方法说明

/api/v1/trade/:idGET交易详情
/api/v1/forceexitPOST强制出场
