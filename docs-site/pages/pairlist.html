Pairlist 管理页面允许你配置 Freqtrade 的交易对过滤器链。过滤器按顺序执行，最终输出白名单。

鍔熻兘

可用过滤器

从 /api/v1/pairlists/available 加载所有可用的过滤器，包括：

  • VolumePairList: 按成交量排序
  • StaticPairList: 静态固定列表
  • AgeFilter: 上市时间过滤
  • SpreadFilter:;乶差过滤
  • PriceFilter: 价格过滤
  • 更多...（取决于安装的插件）

过滤器链配置

在右侧面板配置当前链：

  • 拖拽排序过滤器执行顺序
  • 点击 “移除” 移除不需要的过滤器

评估

点击 “评估” 按钮调用 /api/v1/pairlists/evaluate 生成白名单，结果在下方展示。

相关 API

端点方法说明
