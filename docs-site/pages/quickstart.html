快速开始

快速开始

5 分钟内启动 Freqtrade Desktop，开始你的可视化交易之旅。

前置条件

  • Python 3.11+ 已安装并配置 PATH
  • Node.js 18+ 和 npm
  • TA-Lib C 库已安装（Freqtrade 依赖）
  • 至少一个 Freqtrade 支持的交易所账户
💡 提示

如果你尚未安装 Freqtrade，请先参考 安装指南 完成环境搭建。

快速启动

方式一：从源码运行（推荐开发）

克隆项目
bash
git clone https://github.com/SANS41478/freqtrade-desktop.git
cd freqtrade-desktop
安装前端依赖
bash
npm install
启动 Freqtrade API 服务器
bash
freqtrade api-server --config user_data/config.json
启动桌面应用（开发模式）
bash
# 方式 A：仅浏览器预览
npm run dev

# 方式 B：Electron 桌面窗口
npm run electron:dev

方式二：构建桌面应用

bash
# 构建可分发的桌面应用
npm run electron:build

# 构建产物位于 release/ 目录
# Windows: release/Freqtrade Desktop Setup.exe
# macOS:   release/Freqtrade Desktop.dmg
# Linux:   release/Freqtrade Desktop.AppImage

连接配置

应用默认连接 Freqtrade API 服务器的地址：

配置项默认值说明
API URLhttp://127.0.0.1:8080REST API 地址
WebSocketws://127.0.0.1:8080/api/v1/message/ws实时数据通道
认证方式Basic Auth用户名/密码来自 config.json
⚠️ 安全提醒

默认凭据仅用于本地开发。生产环境请务必修改 config.json 中的 api_server.username 和 api_server.password。

首次使用流程

  1. 启动 Freqtrade API 服务器（确保 DRY-RUN 模式）
  2. 启动桌面应用，查看仪表盘是否正常连接
  3. 在「配置编辑器」中确认交易所 API 密钥配置正确
  4. 在「策略管理」中创建或选择一个策略
  5. 在「回测中心」运行回测，验证策略表现
  6. 确认无误后，关闭 DRY-RUN 模式开始实盘交易
🚨 风险警告

加密货币交易具有高风险。请始终先在 DRY-RUN 模式下充分测试，确认策略有效后再投入真实资金。永远不要使用你无法承受损失的资金进行交易。
