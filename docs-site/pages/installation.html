安装指南

详细的环境搭建和安装步骤，支持 Windows、macOS 和 Linux。

系统要求

组件最低要求推荐配置
操作系统Windows 10 / macOS 12 / Ubuntu 20.04最新版本
Python3.113.12+
Node.js18.020 LTS
内存2 GB4 GB+
磁盘1 GB 可用空间5 GB+
CPU2 vCPU4 vCPU+

安装前置依赖

安装 Python

Windows (winget)
winget install Python.Python.3.12
macOS (Homebrew)
brew install python@3.12
Linux (Ubuntu/Debian)
sudo apt update
sudo apt install python3.12 python3.12-venv python3-pip

安装 TA-Lib C 库

TA-Lib 是 Freqtrade 的核心技术指标库，需要先安装 C 语言底层库。

Windows
# 从 https://github.com/TA-Lib/ta-lib/releases 下载 Windows 二进制包
# 解压后将 ta-lib/include 和 ta-lib/lib 目录添加到系统 PATH
macOS
brew install ta-lib
Linux
wget http://prdownloads.sourceforge.net/ta-lib/ta-lib-0.4.0-src.tar.gz
tar -xzf ta-lib-0.4.0-src.tar.gz
cd ta-lib/
./configure --prefix=/usr
make
sudo make install

安装 Node.js

通用
# 推荐使用 nvm 管理 Node.js 版本
# Windows: https://github.com/coreybutler/nvm-windows
# macOS/Linux:
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash
nvm install 20
nvm use 20

安装 Freqtrade

bash
# 创建虚拟环境
python -m venv .venv

# 激活虚拟环境
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate

# 安装 Freqtrade
pip install freqtrade

# 验证安装
freqtrade --version

安装桌面应用

bash
# 克隆桌面应用仓库
git clone https://github.com/SANS41478/freqtrade-desktop.git
cd freqtrade-desktop/desktop

# 安装依赖
npm install

# 验证安装
npm run lint
? 安装完成

现在可以参阅 快速开始 启动你的第一个桌面交易终端。
