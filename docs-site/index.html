Freqtrade Desktop

Freqtrade 的可视化桌面交易终端，基于 Electron + React + TypeScript 构建，提供实时监控、策略管理、回测分析等完整功能。

快速开始了解更多

实时仪表盘

监控余额、利润、持仓状态，WebSocket 实时数据推送，毫秒级延迟。

回测中心

可视化回测结果，支持多策略对比分析，权益曲线与逐笔统计。

策略编辑器

内置 Monaco Editor，Python 语法高亮，自动补全，模板快速创建。

超参数优化

Optuna 驱动，可视化配置优化空间，实时进度追踪与历史对比。

配置编辑器

JSON 配置可视化表单，实时验证，一键导入导出。

进程管理

自动启动/停止 Freqtrade 后端，系统托盘常驻，一键控制。
