<h2 id="global">全局快捷键</h2>

<table>
  <thead>
    <tr><th>快捷键</th><th>功能</th><th>说明</th></tr>
  </thead>
  <tbody>
    <tr><td><code>Ctrl + 1</code> ~ <code>Ctrl + 9</code></td><td>切换标签页</td><td>快速切换到对应的侧边栏页面</td></tr>
    <tr><td><code>Ctrl + L</code></td><td>打开日志</td><td>快速打开日志查看器</td></tr>
    <tr><td><code>Ctrl + K</code></td><td>搜索</td><td>聚焦搜索框（在浏览器模式下）</td></tr>
    <tr><td><code>Escape</code></td><td>关闭弹窗</td><td>关闭搜索结果等弹出层</td></tr>
    <tr><td><code>F11</code></td><td>全屏</td><td>切换全屏模式</td></tr>
  </tbody>
</table>

<h2 id="editor">编辑器快捷键</h2>

<p>在 Monaco Editor 策略编辑器中，支持所有标准的 VS Code 快捷键：</p>

<table>
  <thead>
    <tr><th>快捷键</th><th>功能</th></tr>
  </thead>
  <tbody>
    <tr><td><code>Ctrl + S</code></td><td>保存文件</td></tr>
    <tr><td><code>Ctrl + Z</code></td><td>撤销</td></tr>
    <tr><td><code>Ctrl + Shift + Z</code></td><td>重做</td></tr>
    <tr><td><code>Ctrl + /</code></td><td>注释/取消注释</td></tr>
    <tr><td><code>Ctrl + D</code></td><td>选择下一个匹配项</td></tr>
    <tr><td><code>Ctrl + F</code></td><td>查找</td></tr>
    <tr><td><code>Ctrl + H</code></td><td>查找和替换</td></tr>
    <tr><td><code>Tab</code></td><td>缩进</td></tr>
    <tr><td><code>Shift + Tab</code></td><td>减少缩进</td></tr>
  </tbody>
</table>
